# pii-vault
PII Vault: use AI tools on files with student data without the AI seeing real names. Download the latest release.

- Mac: `PII-Vault.dmg` (Apple silicon, macOS 13 or later)
- Windows: `PII-Vault-Setup.exe` (Windows 10 or 11, 64-bit)

The engine that finds and replaces personal information is in `engine/`. The Windows app is in `windows/` (see `windows/README.md`).
