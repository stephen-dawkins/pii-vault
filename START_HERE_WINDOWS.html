START HERE: PII Vault for Windows

Use ChatGPT, Copilot, Gemini, Claude, or any AI tool on files with student data, without the AI ever seeing the real names.

Don't have it yet? Download PII Vault for Windows (PII-Vault-Setup.exe).

Setup takes about five minutes. You need a 64-bit PC running Windows 10 (version 1809 or later) or Windows 11, with 8 GB of memory. You don't need to be an administrator. Everything runs on your PC, and nothing is sent anywhere except the protected copies you give your AI tool.

1 Run the installer

Double-click PII-Vault-Setup.exe (it's probably in your Downloads folder). If your browser asks whether to keep the file, choose Keep.

The installer installs PII Vault for your Windows account only, so it doesn't ask for an administrator password. Click Next, leave Put a PII Vault shortcut on the desktop ticked, and click Install. When it finishes, leave Open PII Vault ticked and click Finish.

Click Install. It takes less than a minute.

If the installer says Microsoft Edge WebView2 is being installed, let it finish. PII Vault uses it to draw its window, and most PCs already have it.

2 If you see "Windows protected your PC"

PII Vault was made at Ole Miss and isn't sold through the Microsoft Store, so Windows SmartScreen may show a blue warning the first time you run the installer. That's expected, and you only do this once.

  1. Click More info (under the message, not the big button).
  2. Check that the app name says PII-Vault-Setup.exe, then click Run anyway.

Click More info, then Run anyway. Don't click Don't run.

On a university-managed PC, your IT office may block apps that aren't in the Microsoft Store. If there's no Run anyway button, ask IT to allow PII-Vault-Setup.exe.

3 The welcome screen

  • Pick the AI tool you use (ChatGPT, Copilot, Gemini, Claude, or Other). This only changes the Open button. Protecting and restoring work the same with any tool.
  • Your PII Vault folder is made for you. You don't choose where anything goes (more on the folder below).
  • Recommended: better name finding. PII Vault checks for Ollama, a free app that runs a small, private name-finding model on your PC. If you don't have it, click Download Ollama, run OllamaSetup.exe, and click Install. PII Vault notices by itself; then click Download Model. You can skip this and do it later in Settings.
  • Click Get Started and you're done.

4 Your PII Vault folder

Everything lives in one folder called PII Vault in your user folder (C:\Users\your name\PII Vault). It's kept out of Documents and Desktop on purpose, because those are often backed up to OneDrive, and restored student data should never be copied to the cloud.

Tip: right-click the PII Vault folder and choose Pin to Quick access so it's always one click away.

For AI > ProtectedProtected copies of your files, with names, emails, and IDs swapped for tokens like PERSON_0001. These are the only files you give to an AI tool.
For AI > AI OutputOnly for AI tools that can save files on your PC, like Claude's Cowork mode. Give that tool the For AI folder, never the whole PII Vault folder. Anything it saves here is restored automatically.
RestoredYour finished files with the real data put back. Private. Never upload anything from here to an AI tool.

Your original files are never moved or changed. If a folder ever goes missing, PII Vault makes it again the next time it opens, and Settings > Folders > Repair fixes it on the spot.

5 Using it

  1. Drop a file onto PII Vault: a spreadsheet, Word document, PDF, or text file. You can also paste text.
  2. Check what it found. For spreadsheets, each column gets an action (Tokenize, Year only, and so on). If your spreadsheet has report info above the table, like course title, term, and CRN, PII Vault finds where the real table starts and asks whether to remove that info (the default) or keep it with any names swapped for tokens. Tabs with no table, like assignment instructions, can be included as text or left out.
  3. Type what the AI should do, then click Protect Files.
  4. Click Copy Files, click in your AI tool's message box and press Ctrl+V. Then click Copy Prompt and press Ctrl+V again. Send.
  5. Download the AI's answer. PII Vault spots it in your Downloads folder and puts the real data back by itself. The finished file goes in PII Vault > Restored. You can also drag the file onto PII Vault, or use Paste the AI's Answer if the AI only shows text.
Never upload anything from the Restored folder to an AI tool. Those files have the real names in them.

6 Updates

PII Vault checks for a new version once a day when it opens. When there is one, you'll see Update to 0.x at the bottom of the sidebar. Open Settings > Updates and click Install Update. PII Vault downloads the new version, checks it, installs it, and reopens. Your folders, settings, and jobs stay as they are.

Help

There's no Run anyway button

Click More info first; the button only appears after that. If it's still missing, your PC is managed by IT and blocks unrecognized apps. Ask IT to allow PII-Vault-Setup.exe.

A red bar says PII Vault can't use a folder

Click Repair. If it comes back, click Open Settings. In Windows Security, under Ransomware protection, either turn off Controlled folder access or click Allow an app through Controlled folder access and add PII Vault. Then click Repair again.

My AI's file didn't get restored

Check that Settings > Restore files I download from my AI tool automatically is on. Or just drag the downloaded file onto PII Vault; that always works.

Copy Files didn't attach anything

Some AI tools don't accept pasted files. Use the tool's attach (paperclip) button instead and pick the files from Show Protected Files.

Uninstalling

Open Settings > Apps > Installed apps, find PII Vault, and click Uninstall. Your PII Vault folder is kept, so delete it yourself if you no longer need it.
